Hash collisions: O(n) becomes O(n²)

Classic hash tables can store colliding keys in linked-list buckets. When keys land in the same bucket, insertion may need to scan a growing chain. This model counts equality comparisons when inserting distinct keys.

Educational model: a resized power-of-two bucket array (at most 75% loaded), linked-list chaining, and one comparison per earlier key in that chain. Resizing overhead and hash computation are omitted.
